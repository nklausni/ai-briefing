Wie sich der Impact bestimmt

Bewertet wird aus dem Blickwinkel Coding-Agenten, IDEs und Entwicklungsabläufe. Leitfrage je Meldung: Wie stark verändert sie die tägliche Arbeit, die Werkzeuge oder die Entscheidungen im Bereich Coding-Agenten, IDEs und Entwicklungsabläufe? Eine allgemein große AI-Meldung kann hier niedrig liegen — und umgekehrt. Daraus ergibt sich der Ring (innen = wichtiger).

  • ●○○○○1 — Routine. kleines Update, Bugfix, inkrementell.
  • ●●○○○2 — Nennenswert. neues Feature, aber eher Nische.
  • ●●●○○3 — Relevant. spürbare Verbesserung, betrifft viele.
  • ●●●●○4 — Stark. verändert, wie man arbeitet, oder eröffnet eine neue Möglichkeit.
  • ●●●●●5 — Game-Changer. grundlegender Sprung.

Impact 1 (Routine) ist der äußerste Ring; solche Meldungen führen wir meist nur unter „Überspringen" auf — der äußere Ring bleibt daher oft leer.

GitHub Copilot App: Azure DevOps und Browser Use starten als Public Preview

Agents & Frameworksgithub.blog · 17.11.2026 · ●●●●○ 4/5

GitHub stellt die Azure-DevOps-Integration der Copilot App als Public Preview bereit: Laut Anbieter können Agenten Repositories klonen, Änderungen und Pull Requests erstellen sowie Reviews und CI-Fehler bearbeiten; Cloud-Sitzungen für Azure DevOps werden nicht unterstützt. Gleichzeitig startet Browser Use für die Copilot App, CLI, VS Code und JetBrains, um über eine Erweiterung in Chromium-Browsern unter anderem Formulare zu bedienen und Webanwendungen zu testen. Beide Funktionen müssen aktiviert werden; die standardmäßig ausgeschaltete Browsersteuerung erfordert zusätzlich die Erweiterung sowie aktiviertes Computer Use und Browser Use.
