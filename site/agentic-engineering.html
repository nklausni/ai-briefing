Studie: Coding-Agenten haben kein Gefühl für verstrichene Zeit

Agents & FrameworksThe Decoder · 30.08.2026 · ●●●○○ 3/5

Eine Studie im Rahmen des MATS-Forschungsprogramms zeigt, dass Claude Code und OpenAIs Codex systematisch falsch einschätzen, wie lange eine Aufgabe dauert - Codex lag im Schnitt sechs- bis zehnmal daneben. Beide Systeme bewerten zudem die Qualität der eigenen Arbeit im Schnitt rund 20 Prozentpunkte zu positiv, in einem Fall hielten sie eine Lösung mit tatsächlich 7 bzw. 14,5 Prozent Erfolg für rund 70 Prozent gelungen. Bekommen die Agenten ein Werkzeug, das die verstrichene Zeit meldet, schätzen sie fast immer richtig - ein Hinweis darauf, dass Zeitbewusstsein eine Frage des Kontexts ist, nicht der Modellgröße.
