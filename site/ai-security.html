Lokale Zero-Day-Lücke kann Metas hoch privilegierten Muse-Agenten kapern

Security & GovernanceArs Technica · 2026-09-21 · ●●●●○ 4/5

Der Sicherheitsforscher Patrick Wardle hat für die macOS-App von Meta Muse einen lokalen Zero-Day mit Proof of Concept offengelegt. Ein bereits lokal laufender, unprivilegierter Prozess kann demnach einen undokumentierten Transkriptions-Endpunkt auf einen Angreifer-Server umbiegen, dadurch Spracheingaben und Authentisierungsmaterial abgreifen und die weitreichenden Berechtigungen des Agenten missbrauchen. Es ist kein Angriff aus der Ferne auf einen sauberen Mac; Voraussetzung ist lokale Codeausführung, die Wirkung entspricht aber einer Privilegienausweitung über den Agenten.

Benchling isoliert mandantenfähige Agenten-Codeausführung bis zur DNS-Ebene

Security & GovernanceAWS Machine Learning · 2026-09-21 · ●●●○○ 3/5

Benchling beschreibt eine Defense-in-Depth-Architektur für von KI-Agenten erzeugten wissenschaftlichen Code: AgentCore Code Interpreter im VPC-Modus wird mit kontoweiter Trennung, Route-53-DNS-Firewall, VPC-Endpunktregeln und pro Auftrag ausgestellten STS-Zugangsdaten kombiniert. Benchling meldet mehr als 600 Ausführungssitzungen pro Tag über mehr als 250 Mandanten pro Woche sowie bislang keine Sicherheitsvorfälle; diese Betriebszahlen sind Selbstauskünfte aus einer gemeinsamen Anbieter-Fallstudie.
